# Meme Arena

Вебзастосунок для тематичних мем-раундів на Django та SQLite.

## Запуск локально

У Windows PowerShell з папки проєкту:

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe manage.py migrate
.\.venv\Scripts\python.exe manage.py createsuperuser
.\.venv\Scripts\python.exe manage.py runserver
```

Відкрий `http://127.0.0.1:8000/`. Створи раунд в адмін-панелі (`/admin/`): задай тему, час початку та завершення. Раунд автоматично почнеться у вказаний час і завершиться після часу завершення; статус показується в адмінці та на сторінці раунду. Роботи можна надсилати й голосувати за них лише під час раунду. Результати показують рейтинг авторів за сумою голосів і рейтинг окремих мемів.

Користувачі з акаунтом можуть створювати раунди самостійно за кнопкою **«Створити раунд»**. Обери видимість: публічну, за секретним посиланням або лише для друзів. Раунд за посиланням не показується у загальному списку; передай запрошення з його сторінки. Раунд для друзів доступний після підтвердження запиту в друзі.

У **«Профілі»** можна надсилати й підтверджувати запити в друзі, переглядати список друзів, створені раунди та раунди, у яких ти брав(-ла) участь.

Щоб створити мем, відкрий активний раунд і завантаж зображення. Додавай текстові блоки, перетягуй їх по картинці й налаштовуй шрифт, розмір та колір. Перед публікацією редактор вбудовує текст у зображення.

## Можливості

- Реєстрація та вхід учасників; профіль створюється автоматично.
- Редактор мемів: кілька перетягуваних текстових блоків, налаштування шрифту, розміру та кольору; готове зображення зберігається разом із мемом.
- Завантаження зображень PNG, JPG або WebP (до 5 МБ) з підписом.
- Один голос від кожного учасника за кожну роботу; власні роботи недоступні для голосування.
- Тематичні раунди, поточні результати та рейтинг авторів.
- Створення публічних і приватних раундів користувачами, доступ за секретним посиланням або для підтверджених друзів.
- Профілі з підтвердженням дружби та історією участі й створених раундів.
- Випадкові пари «мем проти мема» з одним голосом на учасника в кожній дуелі.
- Історія останніх переглядів раундів і дуелей для користувачів, які увійшли в акаунт.

Зображення зберігаються у `media/`, а локальна база даних — у `db.sqlite3`.
