# Meme Arena

Вебзастосунок для тематичних мем-раундів на Django та SQLite.

## Запуск локально

У Windows PowerShell з папки проєкту:

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe manage.py migrate
.\.venv\Scripts\python.exe manage.py createsuperuser
.\.venv\Scripts\python.exe manage.py runserver
```

Відкрий `http://127.0.0.1:8000/`. Створи раунд в адмін-панелі (`/admin/`): задай тему, час початку та завершення і статус. Для приймання мемів встанови статус **«Триває»**; роботи можна надсилати і голосувати за них лише між заданими датами. Результати показують рейтинг авторів за сумою голосів і рейтинг окремих мемів.

## Можливості

- Реєстрація та вхід учасників; профіль створюється автоматично.
- Завантаження зображень PNG, JPG або WebP (до 5 МБ) з підписом.
- Один голос від кожного учасника за кожну роботу; власні роботи недоступні для голосування.
- Тематичні раунди, поточні результати та рейтинг авторів.
- Випадкові пари «мем проти мема» з одним голосом на учасника в кожній дуелі.

Зображення зберігаються у `media/`, а локальна база даних — у `db.sqlite3`.
